# 电脑端与手机端功能对照

> 本文件只记录当前代码对照结果，不代表已经完成安卓真机验收。

| 功能 | 电脑端 | 手机端 | 当前边界 |
| --- | --- | --- | --- |
| 新建、编辑、删除日记 | 已支持 | 已支持，包含断网待同步 | 待真机验证锁屏、断网和恢复网络场景 |
| 搜索与筛选 | 支持正文、日期、标签和查看次数 | 支持本地索引、多关键词、高亮、日期、标签和查看次数组合筛选 | 待真机验证大量数据输入和列表性能 |
| 导入与导出 | 支持 JSON、CSV 和本地数据迁移 | 支持 JSON、CSV，重复按日期加正文跳过 | 不恢复旧编号和历史查看次数 |
| 多选与批量操作 | 支持批量删除和标签操作 | 支持批量删除、批量标签、回收站批量恢复和永久删除 | 待真机验证操作中断后的重试体验 |
| 标签 | 支持新增、修改、删除、筛选和批量操作 | 已支持管理、筛选、编辑和离线批量操作 | 待真机验证 |
| 查看次数与随机查看 | 支持查看统计和加权随机查看 | 支持离线查看事件、随机播放和独立随机删除权重 | 待真机验证后台、锁屏和耳机行为 |
| 统计与热力图 | 支持服务器汇总、每日统计、日历和历史热力图 | 已支持服务器汇总、每日历史明细、按日期定位、本地统计和区分本设备事件的历史热力图 | 待真机验证断网、日期切换和统计来源提示 |
| 回收站 | 支持浏览、恢复、批量恢复和永久删除 | 已支持搜索、多选、批量恢复、版本保护永久删除和清空确认 | 待真机验证网络中断和旧服务端兼容提示 |
| 音频与后台播放 | 支持语音、后台播放和缓存 | 已支持多语音包、双遍播放、后台播放和隔离缓存 | 待真机验证蓝牙、锁屏和系统媒体控制 |
| 播放记录 | 支持本地播放状态 | 已支持本地持久化、离线补交、幂等提交和可选恢复 | 待真机验证应用重启、锁屏和跨设备恢复 |
| 正文与标签冲突 | 支持人工审核和受控同步 | 已支持本地与服务器版本对比、人工处理和重试 | 待真机验证复杂网络切换 |
| 本地数据备份与恢复 | 支持数据库备份、恢复、完整性检查和恢复状态查看 | 已支持同服务器本地数据备份、校验、事务恢复和完整性检查；恢复时保留本机界面偏好（不含音频文件） | 待真机验证文件权限与中断恢复 |
| 主题、语言和列表显示 | 支持主题、简体中文、English 和列表列配置 | 已支持主题模式、简体中文和 English 界面、列表字段显隐与日期/查看次数排序；设置本地持久化并在损坏时回退 | 待真机验证系统主题、语言切换与重启恢复 |

手机端不直接访问服务器 SQLite。CSV、JSON、播放记录和本地备份都必须通过手机端本地存储或日记 API 处理；真实密码、Token、数据库、音频和日志不得进入备份文件或代码仓库。
